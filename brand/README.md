# MediaJack Systems brand

Jack's three colours, black, silver and the green of trees after rain, built out into a full palette.
The full guide (usage rules, type, components, print values) is the "MediaJack Systems" design system in Claude.

CMYK values are sRGB converted to FOGRA39 coated (relative colorimetric). Pantone matches are the nearest by eye
data; check them against a swatch book before a spot-colour job.

Logo files in `logo/`: the mark (light and dark grounds, one colour) and the lockup with the wordmark in outlines
(Archivo ExtraBold, 125% width), so they need no font.
